# Misbah Uddin — CV Website

GitHub Pages website:

https://misbahcuir.github.io/

## Files

- `index.html` — responsive CV PDF viewer with SEO metadata and structured data
- `RESUME_MISBAH.pdf` — CV PDF
- `robots.txt` — crawler instructions
- `sitemap.xml` — sitemap for search engines

## GitHub Pages

Upload all files to the root of the repository used for:

`misbahcuir.github.io`

Then enable GitHub Pages from the repository settings.

## Google indexing

After the site is live, add `https://misbahcuir.github.io/` to Google Search Console, inspect the homepage, and request indexing. Submit:

`https://misbahcuir.github.io/sitemap.xml`

Indexing is controlled by Google and is not guaranteed to happen immediately.
